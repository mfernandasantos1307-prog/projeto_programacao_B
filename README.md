# 🌷 StudyBloom

## 🎯 Objetivo
O **StudyBloom** é uma plataforma de organização e acompanhamento acadêmico criada para auxiliar estudantes no gerenciamento de suas atividades, conteúdos e rotina de estudos. A proposta é unir organização acadêmica e motivação visual, permitindo que o estudante acompanhe seus prazos, organize os tópicos de estudo de cada matéria e visualize seu progresso de aprendizado.

## ✨ Funcionalidades

### 🔐 Autenticação
- Cadastro de usuário;
- Login;
- Logout;
- Controle de acesso por usuário.

### 📚 Disciplinas
- Cadastro de disciplinas;
- Edição e exclusão de disciplinas;
- Visualização das disciplinas cadastradas.

### 📖 Conteúdos de Estudo
- Cadastro de tópicos/conteúdos por disciplina;
- Lista de conteúdos para estudar;
- Marcação de conteúdo como concluído (*checklist* de estudo);
- Acompanhamento do progresso de estudo da matéria.

### 📝 Atividades e Avaliações
- Cadastro de trabalhos e provas (com prazo e prioridade);
- Vinculação da atividade com a disciplina correspondente;
- Marcação de atividade como concluída;
- Edição e exclusão de atividades.

### 🔔 Prazos e Alertas
- Destaque para atividades e provas com prazo próximo;
- Organização das pendências por data de entrega;
- Alertas de tarefas pendentes.

### 📊 Painel de Progresso
- Visualização da porcentagem de conteúdos estudados;
- Quantidade de atividades e trabalhos concluídos.
